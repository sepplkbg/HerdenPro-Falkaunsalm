Saisonmanagement

Saison – Auf- und Abtrieb verwalten

Das Herzstück der Almwirtschaft: Saison starten, Kühe auftreieben, vorzeitig abtreiben, Saison beenden. Drei klar getrennte Kategorien.

⛰
Auf der Alm
Alle aktuell oben. Buttons: ↓ vorzeitig abtreiben, ↓ normal abtreiben.
⚠
Vorzeitig abgetrieben
Mit Datum und Grund. Buttons: ↑ zurück auf Alm, ✓ abgerechnet.
🏠
Nicht aufgetrieben
Noch unten. Button: ↑ aufgetrieben. Alle aufgetrieben (Massenaktions-Button).
📅
Saison starten / beendenAlmname, Jahr und Auftriebsdatum festlegen. Beim Beenden wird automatisch ein Saisonarchiv erstellt mit Milch, Alpungstagen, Behandlungsanzahl.
📈
SaisonvergleichAktuelle Saison vs. archivierte Vorjahre. Vergleich Milchleistung, Alpungstage, Küheanzahl. Manuell oder automatisch beim Abtrieb archiviert.

Technologie

PWA – Wie eine native App

HerdenPro ist eine Progressive Web App. Kein App-Store nötig – einfach zum Homescreen hinzufügen. Funktioniert auch ohne Internetverbindung.

📴
Offline-fähig
Service Worker cached die App. Alle Eingaben werden lokal gespeichert und beim nächsten Online-Moment mit Firebase synchronisiert. Oranger Banner zeigt Offline-Modus an.
🔔
Push-Notifications
Automatische Benachrichtigungen: 07:00 Uhr Wartezeiten heute, 20:00 Uhr Wartezeiten morgen, Brunst Tag 19, Geburten 3 + 7 Tage vorher.
📱
Homescreen Installation
iOS: Safari → Teilen → Zum Home-Bildschirm. Android: Chrome → Installieren. Startet dann wie eine native App ohne Browser-Leiste.
🔄
Echtzeit-Sync
Firebase Realtime Database. Alle Geräte sehen Änderungen sofort. Mehrere Nutzer können gleichzeitig arbeiten – Hirte auf der Alm, Bauer im Tal.
⚙
Nav anpassen
Die untere Navigation ist vollständig anpassbar. Per ⚙ Anpassen oder Drag & Drop festlegen welche 4 Module in der Hauptleiste sind. Alles andere im Mehr-Menü.
🌐
Tech-Stack
Single HTML-File PWA. Firebase Compat SDK v9. Open-Meteo Wetter-API (kostenlos). SheetJS für Excel-Import. Vanilla JS – kein Framework, schnell und schlank.
